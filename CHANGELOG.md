# Changelog

## [2.0.0-alpha.16] - 2026-10-31

### Features
- Make the cover wall a visualizer scene, list scenes under Theme settings, and support importing .runescene files
- Use the new Liquid Glass app icon on macOS and iOS
- Support persistent interface scaling across layout and rendering

### Bugs
- Select Skia and precompile acrylic shaders to prevent popup menu stalls on Linux
- Show the build's git hash and commit date on the About page
- Recommend tracks with exact search over analysis data instead of LMDB
- Accelerate audio processing kernels, CRC, and library database lookups
- Standardize English settings names and descriptions
